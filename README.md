# What is Power BI?

1. Power BI is a Business Intelligence and Data Visualization tool from Microsoft.
2. It helps us convert raw data into charts, reports, dashboards, and insights.
3. Power BI is a powerful tool for transforming data into valueable insights.
4. It is used to analysis data model and create interactive report and dashboard.
5. It helps organization to transform raw data into meaningful insights for decision-making

# Key Components
Includes Desktop, Service and Mobile App for comprehensive data analysis.

# Understanding Power BI Components
1. Power BI Desktop :- A powerful tool for data analysis tasks.It is a application where we can builds the reports.
2. Power BI Service :- Accessible platform for collaboration and sharing, it is online service platform used to publish and share 
3. Power BI Mobile App :- Enables data visualization anytime, anywhere. It is an application which can be view reports on tablets or smart phone.

# Power BI turns raw, scattered data into decisions.

Connect to virtually any source — Excel files, SQL databases, SharePoint, web APIs, or cloud services — and pull it into Power BI without manual copy-pasting.

<img width="324" height="181" alt="image" src="https://github.com/user-attachments/assets/793a6ce4-13b3-4c2d-b454-1cf0001ee40e" />

Fix inconsistent formats, remove duplicates, split or merge columns, and reshape messy tables into an analysis-ready structure.
This happens in the Power Query Editor, where every cleaning step is recorded so it can rerun automatically the next time data refreshes.

<img width="347" height="179" alt="image" src="https://github.com/user-attachments/assets/2cae9cb1-0071-49bc-bf17-2a0a9604f518" />

Link separate tables — sales, products, customers, dates — through shared keys so they behave as one connected dataset instead of isolated spreadsheets.

<img width="403" height="155" alt="image" src="https://github.com/user-attachments/assets/cf9e2ccc-4499-48b5-bcd4-66626336771e" />

Write formulas in DAX (Data Analysis Expressions) to build metrics that don't exist in the raw data — running totals, year-over-year growth, custom ratios.
Calculated columns and measures are how "revenue" turns into "revenue vs. same period last year, filtered by whatever the user clicks."

<img width="460" height="168" alt="image" src="https://github.com/user-attachments/assets/4d4011ba-dc65-4218-b790-ee6588a34a0d" />

Arrange bar charts, maps, KPI cards, and tables onto a report canvas, then assemble the most important ones into a single at-a-glance dashboard.
Reports stay interactive: clicking one visual filters the rest, so a viewer can drill from a company-wide total down to one store.
